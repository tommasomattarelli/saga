## [Unreleased]

### Highlights
- [World & DM] NPCs now have a real psychology (ADR 0005): instead of a single friendliness score, every NPC tracks independent feelings toward you — trust, respect, affection and fear by default, and each world can define its own axes (honor, faith, …) with named intensity bands ("suspicious", "terrified") in the world editor. First meetings weigh ×3, reactions shift axis by axis from your actions and dialogue, and the DM sees only what stands out about each person present. World authors can seed starting feelings per NPC.
- [World & DM] Worlds replace templates (ADR 0008): campaigns are now created from a **world library** (`~/.saga/worlds`) holding reusable, file-authored worlds — hierarchical places (regions, sites, buildings, rooms) with real coordinates, travel routes with time cost (moving always costs game time, computed from distance, terrain and travel mode), travel encounters rolled on authored tables, and per-place status the story can change (a burning village stays burning). Each campaign plays on its own frozen copy — editing a world never touches existing saves.
- [World & DM] New **world editor**: create your own world from the "Worlds" page — define your own place types, terrains and travel modes (nothing is hardcoded), edit places/routes/factions/people/encounters in structured forms with picked references (no broken links possible), and share worlds as zip files (export/import). Every save is validated and versioned in a local git history.
- [UI] New in-game world map (read-only): a parchment-and-pins map of the campaign world, opened from a "Map" pill on the play screen — pan/zoom, breadcrumb between map levels, drill-down into places that carry a more detailed map, dashed travel routes between connected places, and a marker on the player's current position.
- [UI] Play screen redesigned to the new clean dark identity (ADR 0013, Sprint 1): self-hosted Newsreader/Instrument Sans type, verdigris accent, hero badge with level/HP, labeled panel pills, serif narration at reading measure with color-coded speakers, rounded action input in plain English, and a new tier-arc dice reveal showing all six outcome tiers. Also fixes: the orphan red companion bar, typed actions lost on a failed submit, history-load failures shown as a false "not started yet" empty state, and a CSS `@import` ordering bug that silently dropped every design token in dev.
- [UI] Redesign propagated to every remaining screen (ADR 0013, Sprint 2): auth is now a single centered card with visible boxed inputs (fixes invisible-input contrast bug); campaign list is a card grid replacing the book-spine shelf; new-campaign wizard flattened (no more 3D page-flip); character sheet is a tabbed rail modal on an opaque panel (fixes gameplay bleeding through); journal, settings, and combat tracker re-skinned to the same tokens. Plain English copy throughout, routed via i18n. Dead ornament assets (map, seal, book-spine, candles, flourishes) removed.
- [Installer] The native Linux installer now works on Debian and every Ubuntu release, not just Ubuntu 24.04: it adds the PostgreSQL PGDG apt repository so Postgres 16 + pgvector install uniformly regardless of the distro's default Postgres major (bookworm ships 15, trixie ships 17).
- [Installer] macOS: pgvector is now built from source against `postgresql@16` (Homebrew's pgvector bottle targets a different Postgres major, so `CREATE EXTENSION vector` previously failed).
- [Installer] The native Linux/macOS installer now fails fast with a clear message when run as root, instead of installing Postgres and then dying mid-way on `initdb` (which refuses to run as root).

### Internal
- ADR 0005 (multi-axis NPC psychology) Sprint 3 — editor: psychology axes section in the world-editor taxonomy form (multiplier/cap, per-axis range/default/bands, add/rename/remove axes; pre-0005 worlds get a "customize" seed of the bundled default) and per-NPC starting-psychology inputs driven by the world's own axes; `EditableWorld` types + en/it strings.
- ADR 0005 (multi-axis NPC psychology) Sprint 2 — LLM surfaces: `npc_director` contract emits `axis_changes` per-axis deltas (malformed entries dropped), NPC prompt renders each axis as number + band label and teaches the axis list + per-turn cap; a completed dialogue always flips `met_player` (zero deltas included); new DM tool `change_npc_psychology` (dict deltas, unknown axis rejected with the world's axis list as candidates) replaces `change_npc_disposition` incl. the `saga.config.yaml` prompt-block reference; DM `<scene>` shows only salient axes per present NPC; auto-created NPCs seed the world's axis defaults; legacy scalar `npc_disposition` handler removed.
- ADR 0005 (multi-axis NPC psychology) Sprint 1 — taxonomy + core: `psychology` block in the world taxonomy meta-schema (axes with range/default/named bands, `first_impression_multiplier`, `max_delta_per_turn`) + bundled default (trust/respect/affection/fear, 5 bands each) shipped in the example world and mirrored as the engine fallback; tier-3 validation of authored `NpcRecord.psychology` seeds; band resolver (`band_label`/`is_salient`); `npc_psychology` updater handler (per-axis deltas, per-turn cap, first-impression ×N with immediate `met_player` flip); world-state schema v6 (trivial rung, no scalar lift); instantiation seeds axis defaults ⊕ authored values.
- ADR 0005 (multi-axis NPC psychology) Sprint 0 — design pass: every fork closed by owner interview; headline revision — psychology axes are **world-defined** in `taxonomy.yaml` (0008 P0 pattern, bundled default trust/respect/affection/fear with per-axis named bands) instead of config-global; `axis_changes` dict contract + per-turn cap + `met_player` first-impression flag; DM tool renamed `change_npc_psychology` (reject-with-candidates); DM scene shows salient axes only; trivial schema rung v5→v6 (no data lift). Implementation plan fixed (S1 core / S2 LLM surfaces / S3 editor).
- ADR 0008 (world model) Sprint 3: the travel engine and runtime — NetworkX route graph (authored edges + interior exits + overlay `edge_overrides`), Naismith/Scarf travel time (config-first constants; per-world terrain multipliers and mode speeds), `move_to` with scoped resolution and reject-with-candidates (never guesses), travel encounters with per-table custom dice and `once` consumption, combat encounters interrupting the journey (`pending_travel`), node-status expiry on clock advance, the single `WorldView` merge accessor over baseline+overlay, and the new hierarchical `<scene>` block (spine breadcrumb, exits, travel options, hard token cap).
- ADR 0008 (world model) Sprint 2: campaigns now instantiate from library Worlds — game home `~/.saga` (SAGA_HOME override) with a git-backed world library seeded from the bundled example; slug→UUID instantiation with composed global-km positions and alias index; new `world_baseline` JSONB column (frozen authored tree, C7 TOAST split) + world identity stamp (`world_slug`/`world_version`); overlay schema v5 (`player_position`, `node_status`, `edge_overrides`, `consumed_encounters`); `templates/` + templates table removed (Alembic 004), `/api/templates` → `/api/worlds`; NPC locations are node UUIDs (J3); git added to the backend Docker image; campaign wizard picks Worlds.
- ADR 0008 (world model) Sprint 1: world meta-schema (world-defined vocabularies per P0 — custom kinds/terrains/travel-modes with engine-contract numeric fields), directory-convention World loader (dir-as-tree, filename-is-slug), three-tier validation (YAML → Pydantic → referential integrity + dynamic per-kind params), and the shipped example World `worlds/the-awakening/` with the copyable default taxonomy. Pure backend; DB wiring lands in Sprint 2.
- Dev Docker Compose: added the `:z` SELinux relabel suffix to host bind mounts so `docker compose up` works on SELinux-enforcing hosts (Fedora/RHEL); the suffix is ignored on non-SELinux systems.
- Installer smoke CI: added a `macos-smoke` job (runs the native installer's Homebrew path on a `macos-latest` runner) alongside the existing Windows and Linux smoke jobs.
- Supply-chain / security CI: Dependabot (`uv` backend, `npm` frontend, github-actions) — routine version updates as one grouped PR per ecosystem (weekly, low noise), plus Dependabot alerts + security updates **enabled** so CVE fixes open individually as soon as they land. CodeQL code-scanning and a dependency-review gate on PRs are **guarded on repo visibility** — they skip while the repo is private (free only on public repos) and activate automatically once it's public. Secret scanning + push protection remain a repo setting to flip at go-public.
